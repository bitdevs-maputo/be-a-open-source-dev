# 3. Issues

Uma **issue** é o registo de uma tarefa, bug ou ideia. Em open source, *nada se faz sem issue*.

## Como usar neste repositório

1. Vai ao separador **Issues** do repositório original.
2. Procura a issue do desafio que queres (ex.: *"Desafio 01 — Calculadora Recursiva"*).
3. Comenta: *"Quero resolver este desafio 🙋"*.
4. Espera o professor atribuir-te (**Assignee**).
5. No PR, escreve `Closes #N` (N = número da issue). Quando o PR for aceite, a issue fecha sozinha.

## Boas práticas
- Título claro e específico.
- Descreve o problema e o resultado esperado.
- Se encontrares erro nos enunciados ou testes, abre uma issue do tipo **Bug / Melhoria**.
- Uma issue = um assunto.
